# ぴょんぴーの大冒険 〜ワライスターをとりもどせ〜

Canvasで動くアクションゲームです。GitHub Pagesで公開して、iPhoneのSafariからホーム画面に追加できます。

宇宙じゅうの“笑い”をうばった魔王から、6つの「ワライスターのかけら」を取りもどす物語。
全35ステージ・6ワールド、オープニングからエンディング、スタッフロールまで遊べます。進行は自動セーブされます。

## あそびかた

| | キーボード | タッチ / パッド |
|---|---|---|
| 移動 | ← → / A D | 十字キー |
| ジャンプ（長押しで高く） | Space / ↑ / W | A |
| ダッシュ | Shift（または同じ方向を2回押し） | B |
| 光線銃 | X / J / Y | X / Y |
| 装備・合体 | Tab | SELECT |
| ポーズ | Enter | START |
| サウンド ON/OFF | M | タイトルの ♪ ボタン |

- 敵は上からふむとピヨる。そのすきに光線銃でたおす。ふんだ瞬間にジャンプで大ジャンプ。
- 同じ光線銃を2つ集めると合体して強くなる。
- 階段をのぼると「空ルート」。カギがあり、ゴール前の宝箱を開けられる。
- ★スイッチは下からたたくか撃つと、赤と青のブロックが入れかわる。
- x-3 などの「のぼりステージ」は山をこえて谷へ。谷のパズルを解いてカギを取らないとバリアが開かない。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `game.js` | ゲーム本体（プレイヤー・敵・武器・マップ・入力） |
| `fx.js` | 演出（画面シェイク、ヒットストップ、パーティクル、環境エフェクト、トランジション、ゴールゲート） |
| `story.js` | 物語（カットシーン）、セーブ、ステージクリア画面、エンディング、スタッフロール、BGM切り替え |
| `chat.js` | 画面下の「そうび＋会話」パネルと、プレイ中のかけあい |
| `gimmicks.js` | 空ルート／のぼりステージ／深い海の生成、カギ・扉・宝箱・スイッチ・バネ |
| `bgm.js` | WebAudioだけで鳴らすBGM（13曲）とジングル |

追加イラストは `IMAGE_PROMPTS.md` のファイル名で `assets/` に置くと自動で使われます。

## 開発用

- ローカル確認: `python -m http.server 4173` を実行して `http://localhost:4173/`
- ステージに直接入る: `?stage=1-3`（ワールド-エリア）、ラスボスは `?stage=final`
- セーブは `localStorage` の `pyonpSaveV1`

## GitHub Pages
